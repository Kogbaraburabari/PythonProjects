| # | Project | Focus |

## Skills demonstrated

- Data cleaning & validation with pandas
- Handling missing values and duplicates
- Data type correction and standardization
- Exploratory data analysis (grouping, aggregation, trend analysis)
- Data visualization with matplotlib and seaborn
- Business insight reporting and stakeholder-ready recommendations
